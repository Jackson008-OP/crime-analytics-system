🚓 Crime Analytics System

A Streamlit web application that analyzes crime data and provides insights through visualizations and basic analytics. It helps in understanding crime patterns and trends in an easy and interactive way.

🚀 Features

📊 Data Visualization — Interactive charts for crime analysis
📍 Crime Insights — Identify patterns based on location and time
📈 Trend Analysis — Year-wise and category-wise crime trends
🧹 Data Processing — Clean and structured dataset handling
🖥️ User Interface — Simple and interactive Streamlit dashboard

🛠️ Tech Stack

Python • Streamlit • Pandas • Matplotlib • Seaborn

📊 Dataset

Source: Crime Dataset (CSV format)
Contains information like:

Crime type
Location
Date & time
Other relevant details

🔍 Analysis Performed
Crime distribution by category
Location-based crime analysis
Time-based trends
Visualization using graphs and charts

📈 Output
Bar charts of crime types
Pie charts for distribution
Trend graphs for analysis
Clean dashboard view
